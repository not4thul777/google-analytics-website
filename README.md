# Google Analytics Website

This is a simple personal website created to **demonstrate and present the skills I learned while completing the Google Analytics course**.

The website serves as a practical project where I can apply concepts from the course, including website analytics, user interaction tracking, and understanding website traffic.

## Purpose

The main purpose of this project is to put my Google Analytics knowledge into practice by:

* Creating and managing a Google Analytics property
* Connecting Google Analytics to a live website
* Tracking website visitors and their interactions
* Understanding user behavior and engagement
* Exploring reports and analytics data

## Technologies Used

* HTML
* CSS
* GitHub Pages
* Google Analytics 4 (GA4)


## About the Project

This is primarily a **learning and demonstration project**, created to showcase the practical skills and concepts I gained through the Google Analytics course.
